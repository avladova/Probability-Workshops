# Glossary / Словарь — Autumn Term (Probability Theory)

> Двуязычный глоссарий по теории вероятностей и математической статистике.  
> Источник: [vladova.ru/Glossary](http://vladova.ru/Glossary)

---

### Probability — Вероятность
The chance of an event occurring, expressed as a number between 0 and 1.

### Sample Space — Пространство элементарных событий
The set of all possible outcomes of an experiment.

### Event — Событие
A subset of the sample space; a specific outcome or a collection of outcomes.

### Random Variable — Случайная величина
A variable whose value is a numerical outcome of a random phenomenon.

### Discrete Random Variable — Дискретная случайная величина
A random variable that can only take on a finite number of values or a countably infinite number of values.

### Continuous Random Variable — Непрерывная случайная величина
A random variable that can take on any value within a given range.

### Permutation — Перестановка
An arrangement of all or part of a set of objects in a specific order. The order of arrangement is crucial.  
Permutations of all elements: nPn = n!  
Permutations involving some elements from n: nPx = n!/(n-x)!

### Distinct permutation — Уникальная перестановка
Permutation involving some identical elements (e.g., MISSISSIPPI: n=11, M=1, I=4, S=4, P=2): n!/(a!·b!·c!·d!)

### Combination — Сочетание
A selection of all or part of a set of objects without regard to the order.  
nCx = n!/(x!(n-x)!)

### Collectively exhaustive events — Совместно исчерпывающие события
If at least one of these events must occur. Their union covers all possible outcomes: P(A∪B)=1.

### Mutually exclusive events — Взаимоисключающие события
The occurrence of one event prevents the occurrence of the other: P(A∩B)=0.

### Statistically independent — Статистически независимые события
If the occurrence or non-occurrence of one event does not affect the probability of the other: P(A·B) = P(A)·P(B).

### Probability Distribution — Распределение вероятностей
A function that describes the probability of each possible value of a random variable.

### Probability Mass Function (PMF) — Функция распределения вероятностей (для дискретных случайных величин)
A function that gives the probability of a discrete random variable taking on a specific value.

### Probability Density Function (PDF) — Функция плотности вероятности (для непрерывных случайных величин)
A function whose integral over a given range gives the probability that a continuous random variable falls within that range.

### Cumulative Distribution Function (CDF) — Интегральная функция распределения
A function that gives the probability that a random variable is less than or equal to a given value.

### Expected Value (Expectation) — Математическое ожидание
The average value of a random variable over many repetitions of the experiment.

### Variance — Дисперсия
A measure of how spread out the values of a random variable are from its expected value.

### Standard Deviation — Среднеквадратичное отклонение
The square root of the variance; another measure of the spread.

### Covariance — Ковариация
A measure of the linear relationship between two random variables.

### Correlation — Корреляция
A standardized measure of the linear relationship between two random variables, ranging from -1 to +1.

### Conditional Probability — Условная вероятность
The probability of an event occurring given that another event has already occurred.

### Bayes' Theorem — Теорема Байеса
A theorem that describes how to update the probability of an event based on new evidence.

### Independence — Независимость
Two events are independent if the occurrence of one does not affect the probability of the other.

### Random Sample — Случайная выборка
A subset of a population selected in such a way that each member of the population has an equal chance of being selected.

### Central Limit Theorem (CLT) — Центральная предельная теорема
A theorem stating that the distribution of the sample mean approaches a normal distribution as the sample size increases.

### Normal Distribution — Нормальное распределение
A bell-shaped probability distribution that is symmetric around its mean.

### Standard Normal Distribution — Стандартное нормальное распределение
A normal distribution with a mean of 0 and a standard deviation of 1.

### Descriptive Statistics — Описательная статистика
Methods for summarizing and presenting data, such as measures of central tendency and dispersion.

### Student's t-distribution — Распределение Стьюдента
A probability distribution used to estimate population parameters when the sample size is small or the population standard deviation is unknown.

### Chi-squared distribution χ² — Распределение хи-квадрат
A probability distribution used in hypothesis testing to determine if there is a significant difference between observed and expected frequencies.

### Degrees of Freedom — Число степеней свободы
The number of independent pieces of information available to estimate a parameter.

### F-distribution — F-распределение
A probability distribution used to compare the variances of two or more populations or to test the overall significance of a regression model.
